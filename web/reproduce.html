Reproduce it

Every figure and number on this site is generated by the open-source code from a trained checkpoint and hashed for provenance — here is how to regenerate the whole bundle.

▸

Build the bundle

Environment

Dependencies are pinned in pyproject.toml and uv.lock. Sync the environment with uv:

shellenvironment
uv sync

Data

Download and extract the Medical Segmentation Decathlon Task06_Lung tumour CT into data/msd/Task06_Lung/:

shelldata layout
data/msd/Task06_Lung/
├── imagesTr/
└── labelsTr/

Pipeline

Preprocess the real CT volumes into a cached 32³ tensor dataset:

shellpreprocess
uv run gradcam-repro real-preprocess --size 32

Train the tumour-presence classifier on that cache:

shelltrain
uv run gradcam-repro real-train --data artifacts/real_ct/msd_lung_presence_32.pt --output artifacts/real_ct/real_ct_presence_cnn_32.pt --device cpu

Export the static web bundle — CT slices, attribution overlays, activations, and benchmark metrics — from the trained checkpoint:

shellweb-export
uv run gradcam-repro web-export --data artifacts/real_ct/msd_lung_presence_32.pt --checkpoint artifacts/real_ct/real_ct_presence_cnn_32.pt --out web/public/data --samples 3 --device cpu

Note: pass --device cpu on machines where the installed Torch build lacks a 3D-conv kernel for the accelerator (e.g. Apple MPS).

Provenance

Every bundle's manifest.json records the SHA-256 of the checkpoint, the data cache, and uv.lock, plus the git commit that produced it — so any figure or number on this site can be traced back to the exact inputs that made it. See DATA_CONTRACT.md for the frozen bundle schema.

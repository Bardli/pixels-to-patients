Reproduce it

Every number in this tour comes from one pipeline that runs on a laptop CPU: raw MSD lung CT → a trained tumour-presence classifier → the seven attribution maps → their scores against the real tumour mask. Here is how to run it end to end.

▸

Reproduce the experiment

1 · Environment

Dependencies are pinned in pyproject.toml and uv.lock:

shell1 · environment
uv sync

2 · Data

Download the Medical Segmentation Decathlon Task06_Lung tumour CT (not redistributed here — get it from the MSD project) and extract it to:

path2 · data
data/msd/Task06_Lung/
├── imagesTr/
└── labelsTr/

3 · Preprocess into patches

Crop the volumes into a cached 32³ classification dataset — tumour-present patches (cropped on the lesion) and non-tumour patches (mask-empty crops):

shell3 · preprocess
uv run gradcam-repro real-preprocess --size 32

→ artifacts/real_ct/msd_lung_presence_32.pt

4 · Train the classifier

Train the tumour-presence CNN on that cache. The checkpoint is not shipped in the repo — you regenerate it here:

shell4 · train
uv run gradcam-repro real-train \
  --data artifacts/real_ct/msd_lung_presence_32.pt \
  --output artifacts/real_ct/real_ct_presence_cnn_32.pt --device cpu

→ artifacts/real_ct/real_ct_presence_cnn_32.pt

5 · Attribute & score

Run the attribution methods on held-out patches and score each heat-map against the real tumour mask. This is the experiment's output — the attribution figures and the exact metrics reported on every method page:

shell5 · attribute + score
uv run gradcam-repro real-demo \
  --data artifacts/real_ct/msd_lung_presence_32.pt \
  --checkpoint artifacts/real_ct/real_ct_presence_cnn_32.pt --device cpu \
  --methods notgradcam gradcam guided_gradcam layercam occlusion integrated_gradients integrated_gradcam

→ figures in artifacts/real_ct/figures/ · scores in artifacts/real_ct/real_ct_scores_32.json

Each map is scored against the ground-truth mask with three metrics — the numbers you saw on the method pages and the compare board:

  • mass_in_gt — share of the attribution mass that falls inside the tumour mask
  • inside_outside_ratio — mean heat inside the mask ÷ mean heat outside
  • pointing_acc — whether the single hottest voxel lands inside the mask

Note: pass --device cpu on machines where the installed Torch build lacks a 3D-conv kernel for the accelerator (e.g. Apple MPS). Omitting --methods runs a faster default subset.

Provenance

Every run hashes the SHA-256 of the checkpoint, the data cache, and uv.lock, together with the git commit that produced it — so any number in this tour traces back to the exact inputs that made it. No figure is hand-drawn. Frozen schema: DATA_CONTRACT.md.

Rebuild this website (optional)

This site is just a static view of that experiment. To regenerate its data bundle and preview it locally: uv run gradcam-repro web-export --data … --checkpoint … --out web/public/data, then serve web/ over http (e.g. python -m http.server) — opening index.html via file:// blocks the data fetch().

Background

An implementation-first tour of attribution methods for medical-imaging CNNs, built for the MICCAI Educational Challenge 2026 ("From Pixels to Patients").

The task

This project reframes the Medical Segmentation Decathlon's Task06_Lung tumour CT as a patch classifier — tumour-present versus non-tumour — and scores attribution against the real tumour segmentation mask, not a hand-drawn region of interest.

Why it matters: a model can be right for the wrong reason. A classifier can reach high accuracy while keying off scanner artifacts, patient positioning, or image borders instead of the lesion itself. Attribution, checked against honest quantitative metrics rather than eyeballed heat-maps, is how you find out whether the network actually localises the tumour.

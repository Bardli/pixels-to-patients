The problem · the network we explain

Inside the network

The problem we solve: a tumour classifier can be right for the wrong reason — keying off scanner artifacts, patient position, or image borders instead of the lesion. To trust it, you have to see where it looks — and that starts with the network itself.

Here is the exact 3D CNN we explain — its shape and parameter count at every stage — plus its live activations and their distributions. Every attribution method taps these feature volumes; Grad-CAM taps stage2.

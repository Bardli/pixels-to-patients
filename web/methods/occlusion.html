Occlusion Sensitivity

No gradients at all — slide a small cube over the volume, blank it out, and measure how much the tumour probability drops. A big drop means an important region.

How it works

Occlusion sensitivity uses no gradients at all. It treats the network as a black box: blank out a region of the input, measure how far the tumour probability falls, and map that drop back onto the volume.

The math

H(p) = max(0, P(c | x) − P(c | x with a cube blanked at p) )

The implementation

The real function from the codebase — nothing hidden. It perturbs the input volume directly — no feature tap and no gradients.

def occlusion_sensitivity(
    model: ToyCNN,
    x: torch.Tensor,
    target: int | torch.Tensor | None = None,
    mask_size: int = 4,
    stride: int = 4,
    fill_value: float | None = None,
    batch_size: int = 64,
) -> torch.Tensor:
    model.eval()
    with torch.no_grad():
        logits = model(x)
        if target is None:
            target_tensor = logits.argmax(dim=1)
        elif isinstance(target, int):
            target_tensor = torch.full((x.shape[0],), target, device=x.device, dtype=torch.long)
        else:
            target_tensor = target.to(device=x.device, dtype=torch.long)
        base_probs = logits.softmax(dim=1).gather(1, target_tensor.view(-1, 1)).view(-1)
    batch, _, depth, height, width = x.shape
    heatmap = torch.zeros((batch, 1, depth, height, width), device=x.device, dtype=x.dtype)
    counts = torch.zeros_like(heatmap)
    fill_tensor = (
        x.detach().mean(dim=(1, 2, 3, 4), keepdim=True)
        if fill_value is None
        else None
    )
    positions = [
        (z, y, x0)
        for z in range(0, depth - mask_size + 1, stride)
        for y in range(0, height - mask_size + 1, stride)
        for x0 in range(0, width - mask_size + 1, stride)
    ]
    for start in range(0, len(positions), batch_size):
        chunk = positions[start : start + batch_size]
        occluded = x.repeat_interleave(len(chunk), dim=0).clone()
        for sample_idx in range(batch):
            offset = sample_idx * len(chunk)
            for j, (z, y, x0) in enumerate(chunk):
                replacement = fill_value if fill_tensor is None else fill_tensor[sample_idx]
                occluded[
                    offset + j,
                    :,
                    z : z + mask_size,
                    y : y + mask_size,
                    x0 : x0 + mask_size,
                ] = replacement
        with torch.no_grad():
            probs = model(occluded).softmax(dim=1)
        probs = probs.view(batch, len(chunk), -1)
        target_probs = probs.gather(
            2, target_tensor.view(batch, 1, 1).expand(batch, len(chunk), 1)
        ).squeeze(2)
        drops = base_probs[:, None] - target_probs
        for j, (z, y, x0) in enumerate(chunk):
            heatmap[
                :,
                :,
                z : z + mask_size,
                y : y + mask_size,
                x0 : x0 + mask_size,
            ] += drops[:, j].view(batch, 1, 1, 1, 1)
            counts[:, :, z : z + mask_size, y : y + mask_size, x0 : x0 + mask_size] += 1
    heatmap = (heatmap / counts.clamp_min(1)).clamp_min(0)
    return normalize_map(heatmap)

Gotchas that make it work

  1. The cube is filled with the per-volume MEAN, not zero — zero-fill injects a fake black-cube edge the network reacts to, corrupting the map.
  2. Model-agnostic — treats the network as a black box; no backprop.
  3. stride/mask_size trade resolution against compute; it is by far the slowest method here.

Occlusion Sensitivity

No gradients at all. Slide a small cube over the volume, blank it out, and measure how much the malignancy probability drops. A big drop means an important region.

How it works

Occlusion sensitivity uses no gradients at all. It treats the network as a black box: blank out a region of the input, measure how far the malignancy probability falls, and map that drop back onto the volume.

The math

H(p) = max ( 0 , P(c|x) − P(c|x blanked at p) ) probability drop when a cube is blanked
  • H(p) — the heat at voxel position p: how much blanking p hurts the class score
  • max(0, ·) — keep only positive probability drops (evidence for the class)
  • P(c | x) — the model's softmax probability of class c on the intact volume x
  • P(c | x with a cube blanked at p) — the same probability after replacing a small cube at p with the per-volume mean (not zero, which would inject a fake black-cube edge). No gradients are used.

The implementation

Verbatim from the codebase. It perturbs the input volume directly, with no feature tap and no gradients. It is the one method of the seven that needs no backward pass at all.

scripts/gradcam3d_viz.py_compute_occlusion()
def _compute_occlusion(model, x_batch, target_shape, target_cls,
                       extract_logits_fn, config, pid):
    """Occlusion Sensitivity via MONAI."""
    from monai.visualize import OcclusionSensitivity
    wrapped = _MonaiGradCamWrapper(model, None, extract_logits_fn)
    wrapped = wrapped.to(x_batch.device)
    wrapped.eval()
    occ = OcclusionSensitivity(nn_module=wrapped,
                               mask_size=config.occ_mask_size,   # 16
                               n_batch=config.occ_n_batch)
    occ_map, _ = occ(x_batch, class_idx=target_cls,
                     overlap=config.occ_overlap)
    occ_arr = occ_map[0, 0].cpu().numpy()

    # MONAI returns the class SCORE with the region occluded, not the drop
    # in score. High therefore means "occluding here barely changed the
    # prediction" -- the region is UNimportant, the inverse of every other
    # method's convention. Negate so high = important.
    # Measured before this fix: in-lesion 0.00 while surrounding vessels
    # ran 0.6-0.8, i.e. the nodule read as the coldest thing in the volume.
    occ_arr = -occ_arr

    occ_arr = _upsample_to(occ_arr, target_shape)
    return occ_arr

Gotchas that make it work

  1. The cube is filled with the per-volume MEAN, not zero. Zero-fill injects a fake black-cube edge that the network reacts to, corrupting the map.
  2. Model-agnostic — treats the network as a black box; no backprop.
  3. stride/mask_size trade resolution against compute; it is by far the slowest method here.

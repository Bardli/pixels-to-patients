Guided Grad-CAM

Multiply Grad-CAM's coarse class-localisation by guided backpropagation's fine input-space edges — a map that is sharp and class-discriminative.

How it works

Guided Grad-CAM sharpens Grad-CAM's coarse localisation with guided backpropagation's high-resolution edges — combining where (Grad-CAM) with what (guided backprop).

The math

GGC = normalize( | GuidedBP(x,c) ⊙ Up(Grad-CAMc) | )

The implementation

The real function from the codebase — nothing hidden. It reuses gradcam() and guided_backprop_raw(), then takes their product.

src/gradcam_repro/attribution.pyguided_gradcam()
def guided_gradcam(
    model: ToyCNN,
    x: torch.Tensor,
    target: int | torch.Tensor | None = None,
    layer: str = TARGET_LAYER,
) -> torch.Tensor:
    cam = gradcam(model, x, target, layer=layer, normalize=True)
    guided = guided_backprop_raw(model, x, target)
    product = guided * cam
    return normalize_map(product.abs().sum(dim=1, keepdim=True))

Gotchas that make it work

  1. Guided-ReLU hooks zero out negative gradients on the backward pass (Springenberg et al., 2015).
  2. Grad-CAM supplies localisation, guided backprop supplies resolution — neither alone is both.
  3. Element-wise product, then absolute value summed over channels.

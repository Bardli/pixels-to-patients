Guided Grad-CAM

Multiply Grad-CAM's coarse class-localisation by guided backpropagation's fine input-space edges. The product is sharp and class-discriminative.

How it works

Guided Grad-CAM sharpens Grad-CAM's coarse localisation with guided backpropagation's high-resolution edges, so it carries both the where and the what.

The math

GGC = normalize ( | GuidedBP(x,c) ⊙ Up(Grad-CAMc) | ) sharp guided-backprop edges × the Grad-CAM map
  • GGC — the Guided Grad-CAM map
  • normalize — min-max rescale the result to [0, 1]
  • | · | — absolute value (magnitude), taken voxel-wise
  • GuidedBP(x, c) — guided backpropagation: the input-space gradient with ReLUs masked to pass only positive signal, giving sharp high-resolution edges
  • ⊙ — element-wise product
  • Up(Grad-CAMc) — the class-c Grad-CAM map upsampled to input size

The implementation

Verbatim from the codebase. It reuses gradcam() and guided_backprop_raw(), then takes their product.

scripts/gradcam3d_viz.py_compute_guided_gradcam()
def _compute_guided_gradcam(model, x_batch, truegradcam_raw, stages, stage_names,
                            target_shape, target_cls, extract_logits_fn, pid):
    """Guided Grad-CAM: guided backprop saliency * Grad-CAM per stage."""
    device = x_batch.device
    with guided_backprop_context(model):
        x_input = x_batch.clone().requires_grad_(True)
        logits_gb = _as_two_column(extract_logits_fn(model(x_input)))
        logits_gb[0, target_cls].backward()
        guided_bp = x_input.grad[0].mean(dim=0).cpu().numpy()
    model.zero_grad()

    raw = {}
    for sname in stage_names:
        gc = truegradcam_raw[sname]
        gc_relu = np.maximum(gc, 0)
        raw[sname] = guided_bp * gc_relu
        _validate_att_volume(raw[sname], target_shape, sname, "guided_gradcam", pid)
    return raw

Gotchas that make it work

  1. Guided-ReLU hooks zero out negative gradients on the backward pass (Springenberg et al., 2015).
  2. Grad-CAM supplies localisation, guided backprop supplies resolution. Neither alone is both.
  3. Element-wise product, then absolute value summed over channels.

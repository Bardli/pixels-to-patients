Grad-CAM

Weight each feature-map channel by how strongly its average gradient pushes the target class, sum the weighted channels, keep the positive part, and upsample. The canonical class-discriminative heat-map.

How it works

Grad-CAM asks one question of a trained network: which feature-map channels mattered for this class, and where were they active? It answers with a single backward pass.

The math

αkc = GAP( ∂yc / ∂Ak )  — average-pool the gradient over the volume
Lc = ReLU( Σk αkc · Ak )  — weighted sum of channels, keep positive
heat = trilinear-upsample( Lc → input size )
  • Ak — the k-th feature-map channel at the stage2 tap (16 channels)
  • yc — the network's raw score (logit) for the target class c (tumour-present vs. not)
  • ∂yc/∂Ak — gradient of that score w.r.t. channel k: how much each voxel of the channel moves the score
  • GAP — global-average pool: average over the whole D×H×W volume, giving one number per channel
  • αkc — the resulting weight for channel k: how important it is for class c
  • Σk — sum over all channels k
  • ReLU — keep positives, zero the rest (only evidence for the class)
  • Lc — the low-resolution class-c localization map (the raw CAM)
  • trilinear-upsample — resize Lc from the feature grid back up to the input volume size

The implementation

The real function from the codebase — nothing hidden. The CAM is tapped at stage2, a 16-channel feature volume.

src/gradcam_repro/attribution.pygradcam()
def gradcam(model, x, target=None, layer="stage2", normalize=True):
    model.eval()
    model.zero_grad(set_to_none=True)
    logits, activation = _cam_forward(model, x, layer)   # activation.retain_grad()
    score_for_target(logits, target).backward()          # one backward pass
    gradients = activation.grad                           # dyc / dA^k
    weights = gradients.mean(dim=(2, 3, 4), keepdim=True) # a_k^c = GAP(grad)
    cam = (weights * activation).sum(dim=1, keepdim=True).clamp_min(0)  # ReLU
    cam = upsample_to_input(cam, x)                       # trilinear
    return normalize_map(cam) if normalize else cam

The shared code

Every method here builds on two pieces of shared code. First, the network exposes its intermediate feature volumes, so an attribution method can tap any stage:

src/gradcam_repro/model.pyRealCtCNN.forward()
def forward(self, x, return_features=False):
    features = {}
    x = self.stage1(x); features["stage1"] = x
    x = self.stage2(x); features["stage2"] = x   # ← the CAM tap
    x = self.stage3(x); features["stage3"] = x
    logits = self.classifier(self.pool(x).flatten(1))
    if return_features:
        return logits, features
    return logits

Second, a small scaffold hooks the tapped activation (keeping its gradient), selects the class to explain, and normalises + upsamples the result. Every method calls these helpers:

src/gradcam_repro/attribution.pyshared scaffold
TARGET_LAYER = "stage2"

def _cam_forward(model, x, layer=TARGET_LAYER):
    logits, features = model(x, return_features=True)
    activation = features[layer]
    activation.retain_grad()              # keep grad on a non-leaf tensor
    return logits, activation

def score_for_target(logits, target):     # the logit to explain, summed for backward()
    target = logits.argmax(1) if target is None else target
    return logits.gather(1, target.view(-1, 1)).sum()

def upsample_to_input(heatmap, x):        # feature grid → input grid
    return F.interpolate(heatmap, size=x.shape[-3:], mode="trilinear", align_corners=False)

def normalize_map(heatmap, eps=1e-8):     # min-max each map to [0, 1]
    flat = heatmap.flatten(1)
    view = (heatmap.shape[0],) + (1,) * (heatmap.ndim - 1)
    lo = flat.min(1).values.view(view); hi = flat.max(1).values.view(view)
    return (heatmap - lo) / (hi - lo + eps)

The computation, step by step

Below, watch Grad-CAM run end to end on a real case.

  1. A CT patch enters the network. One 32×32×32 lung-CT patch, HU-normalised to [0,1]. The classifier must decide: tumour-present or not. x ∈ ℝ^(1 × 32 × 32 × 32)
  2. Forward pass → three stages, one tap. The CNN stacks three conv stages — stage1 → stage2 → stage3 — each a feature volume of shrinking size. Grad-CAM taps the middle one, stage2 (16 channels at 8×8×8). A = stage2(x) ∈ ℝ^(16 × 8 × 8 × 8)
  3. Backward pass → one weight per channel. A single backward pass from the target logit gives ∂yᶜ/∂Aᵏ. Average each channel's gradient over the volume → a scalar importance weight αₖ. (Computed live in the notebook.) αₖᶜ = GAP( ∂yᶜ / ∂Aᵏ )
  4. Weighted sum, ReLU, upsample. Weight the channels, sum them, keep the positive part, and trilinearly upsample back to the input grid. This is the raw Grad-CAM heat-map. Lᶜ = Up( ReLU( Σₖ αₖᶜ Aᵏ ) )
  5. Overlay to localise. Laid over the CT, the heat-map shows where the network's evidence for the class lives — hopefully on the lesion. Each method page scores whether it does, against the tumour mask. read-out = CT ⊕ heat

Gotchas that make it work

  1. Gradients are global-average-pooled over the whole 3D volume to get one weight per channel — the core CAM assumption that a channel's importance is spatially uniform.
  2. ReLU comes after the weighted sum, not before. It keeps only evidence for the target class, which is why Grad-CAM maps look "positive".
  3. Tapped at stage2, so the raw map is at feature-volume resolution, then trilinearly upsampled. The heat-map is inherently coarse — a property of where you tap.
  4. activation.retain_grad() is mandatory — stage2 is a non-leaf tensor, so without it activation.grad is None.

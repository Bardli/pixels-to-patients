How it works

Integrated Grad-CAM moves Integrated Gradients into feature space: it path-integrates the gradients with respect to the CAM-layer activations, weighted by how far those activations moved from a baseline.

The math

IGC = normalize( Up( | ΔA ⊙ (1/steps) Σα ∂yc/∂A(xα) | ) )
ΔA = A(x) − A(baseline)
  • IGC — the Integrated Grad-CAM map
  • normalize / Up — min-max rescale to [0, 1], then trilinear-upsample to input size
  • | · | — absolute value (magnitude)
  • ΔA = A(x) − A(baseline) — the stage2 feature difference between the input x and the baseline (the per-volume mean volume, not zero)
  • ⊙ — element-wise product
  • (1/steps) Σα — average over steps = 20 points along the path
  • ∂yc/∂A(xα) — gradient of the class-c score w.r.t. stage2 features at interpolation point xα

The implementation

The real function from the codebase — nothing hidden. It path-integrates gradients at the stage2 tap from a per-volume mean baseline.

src/gradcam_repro/attribution.pyintegrated_gradcam()
def integrated_gradcam(
    model: ToyCNN,
    x: torch.Tensor,
    target: int | torch.Tensor | None = None,
    layer: str = TARGET_LAYER,
    steps: int = 20,
) -> torch.Tensor:
    model.eval()
    baseline = torch.ones_like(x) * x.detach().mean(dim=(1, 2, 3, 4), keepdim=True)
    with torch.no_grad():
        _, input_features = model(x, return_features=True)
        _, baseline_features = model(baseline, return_features=True)
        feature_delta = input_features[layer] - baseline_features[layer]
    total_grad = torch.zeros_like(feature_delta)
    for alpha in torch.linspace(0, 1, steps + 1, device=x.device, dtype=x.dtype)[1:]:
        model.zero_grad(set_to_none=True)
        x_step = (baseline + alpha * (x - baseline)).detach()
        logits, activation = _cam_forward(model, x_step, layer)
        score_for_target(logits, target).backward()
        gradients = activation.grad
        if gradients is None:
            raise RuntimeError("Integrated Grad-CAM hook did not receive activation gradients")
        total_grad += gradients
    contribution = (total_grad / steps) * feature_delta
    cam = contribution.abs().sum(dim=1, keepdim=True)
    return normalize_map(upsample_to_input(cam, x))

Gotchas that make it work

  1. Baseline is the per-volume mean (not zero) in input space.
  2. Integration is over the stage2 feature gradients, then multiplied by the feature delta ΔA.
  3. Combines IG's path-integration with CAM's feature-localisation.

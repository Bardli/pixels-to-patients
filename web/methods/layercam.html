LayerCAM

Like Grad-CAM, but weight each activation by its own positive gradient at that location rather than one pooled weight per channel — a finer, spatially-varying map from the same tap point.

How it works

LayerCAM keeps Grad-CAM's idea but weights each activation by its own positive gradient at that location, giving spatially-varying weights instead of one weight per channel.

The implementation

The real function from the codebase — nothing hidden. Tapped at stage2 like Grad-CAM, but the weighting is element-wise rather than global-average-pooled.

src/gradcam_repro/attribution.pylayercam()
def layercam(
    model: ToyCNN,
    x: torch.Tensor,
    target: int | torch.Tensor | None = None,
    layer: str = TARGET_LAYER,
) -> torch.Tensor:
    model.eval()
    model.zero_grad(set_to_none=True)
    logits, activation = _cam_forward(model, x, layer)
    score_for_target(logits, target).backward()
    gradients = activation.grad
    if gradients is None:
        raise RuntimeError("LayerCAM hook did not receive activation gradients")
    cam = (gradients.clamp_min(0) * activation).sum(dim=1, keepdim=True).clamp_min(0)
    return normalize_map(upsample_to_input(cam, x))

Gotchas that make it work

  1. Per-voxel weights, not global-average-pooled → finer detail than Grad-CAM at the same layer.
  2. ReLU on the gradient keeps only positive local evidence.
  3. Still tapped at stage2 and trilinearly upsampled.

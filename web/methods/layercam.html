LayerCAM

Like Grad-CAM, but weight each activation by its own positive gradient at that location rather than one pooled weight per channel. The result is a finer, spatially varying map from the same tap point.

How it works

LayerCAM keeps Grad-CAM's idea but weights each activation by its own positive gradient at that location, giving spatially-varying weights instead of one weight per channel.

The math

L = ReLU ( ∑k ReLU ( ∂yc∂Ak ) ⊙ Ak ) per-voxel positive gradients weight each channel
  • L — the LayerCAM map
  • ReLU — keep positive values, zero the rest
  • Σk — sum over all feature channels k
  • ∂yc/∂Ak — per-voxel gradient of the class-c score yc w.r.t. channel Ak, kept per-voxel (not global-average-pooled, the key difference from Grad-CAM)
  • ⊙ — element-wise (Hadamard) product: multiply the positive gradient by the activation voxel-by-voxel
  • Ak — the k-th feature-map channel at the conv_block tap

The implementation

Verbatim from the codebase. Tapped at conv_block like Grad-CAM, but the weighting is element-wise rather than global-average-pooled.

scripts/gradcam3d_viz.py_compute_layercam()
def _compute_layercam(model, x_batch, stages, stage_names, target_shape,
                      target_cls, extract_logits_fn, pid):
    """Layer-CAM: ReLU(grad * activation) summed over channels, per stage."""
    device = x_batch.device
    activations = {}
    gradients = {}
    handles = []

    for sname, stage_mod in zip(stage_names, stages):
        def fwd_hook(mod, inp, out, _s=sname):
            activations[_s] = out.detach()
        def bwd_hook(mod, grad_in, grad_out, _s=sname):
            gradients[_s] = grad_out[0].detach()
        handles.append(stage_mod.register_forward_hook(fwd_hook))
        handles.append(stage_mod.register_full_backward_hook(bwd_hook))

    x_lc = x_batch.clone().requires_grad_(True)
    logits_lc = _as_two_column(extract_logits_fn(model(x_lc)))
    logits_lc[0, target_cls].backward()
    for h in handles:
        h.remove()
    model.zero_grad()

    raw = {}
    for sname in stage_names:
        act = activations[sname]
        grad = gradients[sname]
        lc = F.relu(grad * act).sum(dim=1)[0].cpu().numpy()
        lc = _upsample_to(lc, target_shape)
        _validate_att_volume(lc, target_shape, sname, "layercam", pid)
        raw[sname] = lc
    return raw

Gotchas that make it work

  1. Per-voxel weights, not global-average-pooled → finer detail than Grad-CAM at the same layer.
  2. ReLU on the gradient keeps only positive local evidence.
  3. Still tapped at conv_block and trilinearly upsampled.

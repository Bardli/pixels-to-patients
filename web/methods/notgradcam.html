The sparsity is real but it lives at the voxel level, not the channel level — — of the individual activations in this tensor are exactly zero. That is precisely why averaging is a weak localiser: mean over hundreds of busy channels dilutes the class-specific signal into the anatomy that is merely present.

How it works

The mean activation map is the honest baseline: no gradients and no target class — just the mean of the feature-map channels at the tap layer, upsampled. It shows what the network is active on, before any class-discriminative signal is added.

The math

M(x) = Up ( 1K∑k Ak (x) ) mean over channels, then upsample
  • M(x) — the saliency map produced for the input volume x
  • Ak — the k-th feature-map channel at the conv_block tap (640 channels)
  • (1/K) Σk — the plain mean over all K = 640 channels; no gradients and no class — that is the whole point of this baseline
  • Up — trilinear-upsample the mean map back to the input volume size

The implementation

The real function from the codebase — nothing hidden. It averages the 640 conv_block feature channels; note that no target class is passed in at all.

scripts/gradcam3d_viz.py_compute_notgradcam()
def _compute_notgradcam(model, x_batch, stages, stage_names,
                        target_shape, pid):
    """Activation maps: mean channel activation per stage (no gradients)."""
    raw = {}
    for sname, stage_mod in zip(stage_names, stages):
        features = []
        def hook_fn(mod, inp, out, _f=features):
            _f.append(out)
        handle = stage_mod.register_forward_hook(hook_fn)
        with torch.no_grad():                  # no backward pass at all
            model(x_batch)
        handle.remove()
        feat = features[0][0]                  # (640, 16, 16, 16)
        att = feat.mean(dim=0).float().cpu().numpy()   # mean over channels
        att = _upsample_to(att, target_shape)          # -> (64, 128, 128)
        raw[sname] = att
    return raw

Gotchas that make it work

  1. Class-agnostic — no target class is passed at all; the map is identical whichever class you ask about.
  2. No backward pass — pure forward activations, torch.no_grad().
  3. It answers "where is the network active?", not "where for THIS class?" — the honest baseline against which Grad-CAM's value is judged.

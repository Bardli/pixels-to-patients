How it works

The mean activation map is the honest baseline: no gradients and no target class — just the mean of the feature-map channels at the tap layer, upsampled. It shows what the network is active on, before any class-discriminative signal is added.

The math

M(x) = Up ( 1K∑k Ak (x) ) mean over channels, then upsample
  • M(x) — the saliency map produced for the input volume x
  • Ak — the k-th feature-map channel at the stage2 tap (16 channels)
  • (1/K) Σk — the plain mean over all K = 16 channels; no gradients and no class — that is the whole point of this baseline
  • Up — trilinear-upsample the mean map back to the input volume size

The implementation

The real function from the codebase — nothing hidden. It averages the stage2 feature channels; note the target argument is deliberately unused.

src/gradcam_repro/attribution.pynotgradcam()
def notgradcam(
    model: ToyCNN, x: torch.Tensor, target: int | torch.Tensor | None = None, layer: str = TARGET_LAYER
) -> torch.Tensor:
    del target
    model.eval()
    with torch.no_grad():
        _, features = model(x, return_features=True)
        cam = features[layer].mean(dim=1, keepdim=True)
    return normalize_map(upsample_to_input(cam, x))

Gotchas that make it work

  1. Class-agnostic — the target argument is ignored; the map is identical for every class.
  2. No backward pass — pure forward activations, torch.no_grad().
  3. It answers "where is the network active?", not "where for THIS class?" — the honest baseline against which Grad-CAM's value is judged.

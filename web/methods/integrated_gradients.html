Integrated Gradients

Integrate the input-space gradients along a straight path from a black baseline to the real scan. Satisfies the completeness axiom: attributions sum to the prediction difference between scan and baseline.

How it works

Integrated Gradients works in input space: it integrates the gradient of the target logit along a straight path from a baseline to the real scan, and satisfies the completeness axiom.

The math

IGi(x) = (xi − x'i) · ∫₀¹ ∂yc(x' + α(x − x')) / ∂xi dα  ≈  Riemann sum over steps
  • IGi(x) — the attribution assigned to input voxel i
  • xi — the value of input voxel i
  • x'i — voxel i of the baseline x' (here the zero volume)
  • ∫01 … dα — integral along the straight-line path from baseline x' to input x
  • α — interpolation coefficient in [0, 1] positioning a point on that path
  • ∂yc/∂xi — gradient of the class-c score yc w.r.t. input voxel i, at the interpolated point
  • Riemann sum — the integral is approximated by averaging gradients over steps = 50 discrete values of α

The implementation

The real function from the codebase — nothing hidden. It integrates gradients in input space over a 50-step path from a zero baseline.

src/gradcam_repro/attribution.pyintegrated_gradients()
def integrated_gradients(
    model: ToyCNN,
    x: torch.Tensor,
    target: int | torch.Tensor | None = None,
    steps: int = 50,
    smooth_sigma: float = 0.8,
) -> torch.Tensor:
    model.eval()
    baseline = torch.zeros_like(x)
    total_grad = torch.zeros_like(x)
    for alpha in torch.linspace(0, 1, steps + 1, device=x.device, dtype=x.dtype)[1:]:
        model.zero_grad(set_to_none=True)
        x_step = (baseline + alpha * (x - baseline)).detach().requires_grad_(True)
        logits = model(x_step)
        grad = torch.autograd.grad(score_for_target(logits, target), x_step)[0]
        total_grad += grad
    attribution = (x - baseline) * total_grad / steps
    heatmap = attribution.abs().sum(dim=1, keepdim=True)
    heatmap = gaussian_blur3d(heatmap, sigma=smooth_sigma)
    return normalize_map(heatmap)

Gotchas that make it work

  1. Baseline is zeros (a black volume); the baseline choice materially changes the attribution.
  2. Approximated with a 50-step Riemann sum.
  3. Input-resolution → fine but noisy, so a small 3D Gaussian blur is applied.
  4. Absolute value summed over channels (single-channel CT → just the magnitude).

Integrated Gradients

Integrate the input-space gradients along a straight path from a black baseline to the real scan. Satisfies the completeness axiom: attributions sum to the prediction difference between scan and baseline.

How it works

Integrated Gradients works in input space: it integrates the gradient of the target logit along a straight path from a baseline to the real scan, and satisfies the completeness axiom.

The math

IGi(x) = ( xi − x′i ) · ∫01 ∂yc(x′+α⁢(x−x′)) ∂xi dα integrate input gradients along a path from a zero baseline
≈ Riemann sum over steps 50-step discrete approximation
  • IGi(x) — the attribution assigned to input voxel i
  • xi — the value of input voxel i
  • x'i — voxel i of the baseline x' (here the zero volume)
  • ∫01 … dα — integral along the straight-line path from baseline x' to input x
  • α — interpolation coefficient in [0, 1] positioning a point on that path
  • ∂yc/∂xi — gradient of the class-c score yc w.r.t. input voxel i, at the interpolated point
  • Riemann sum — the integral is approximated by averaging gradients over steps = 50 discrete values of α

The implementation

Verbatim from the codebase. It integrates gradients in input space over a 50-step path from a zero baseline.

scripts/gradcam3d_viz.py_compute_integrated_gradients()
def _compute_integrated_gradients(model, x_batch, target_shape, target_cls,
                                  extract_logits_fn, config, pid):
    """Integrated Gradients with optional Gaussian smoothing."""
    device = x_batch.device
    baseline = torch.zeros_like(x_batch)
    n_steps = config.ig_n_steps
    batch_size = config.ig_batch_size
    alphas = torch.linspace(0, 1, n_steps + 1, device=device)
    accumulated_grads = torch.zeros_like(x_batch, device="cpu")

    for i in range(0, n_steps + 1, batch_size):
        batch_alphas = alphas[i:i + batch_size]
        diff = x_batch - baseline
        x_interp = baseline + batch_alphas.view(-1, 1, 1, 1, 1) * diff
        x_interp = x_interp.detach().requires_grad_(True)
        logits_ig = _as_two_column(extract_logits_fn(model(x_interp)))
        logits_ig[:, target_cls].sum().backward()
        accumulated_grads += x_interp.grad.sum(dim=0, keepdim=True).cpu()
        model.zero_grad()

    ig_attr = (accumulated_grads / (n_steps + 1)) * (x_batch.cpu() - baseline.cpu())
    ig_arr = ig_attr[0].mean(dim=0).numpy()
    ig_arr = np.abs(ig_arr)

    if config.ig_smooth_sigma > 0:
        from scipy.ndimage import gaussian_filter
        ig_arr = gaussian_filter(ig_arr, sigma=config.ig_smooth_sigma)

    _validate_att_volume(ig_arr, target_shape, "input_resolution",
                         "integrated_gradients", pid)
    return ig_arr

Gotchas that make it work

  1. Baseline is zeros (a black volume); the baseline choice materially changes the attribution.
  2. Approximated with a 50-step Riemann sum.
  3. Input-resolution → fine but noisy, so a small 3D Gaussian blur is applied.
  4. Absolute value summed over channels (single-channel CT → just the magnitude).

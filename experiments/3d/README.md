# 3D Grad-CAM Experiments

`gradcam3d_viz.py` is the project-independent 3D visualization script supplied
from `/Users/baiduli/Downloads/gradcam3d_viz (1).py`.

It is intended for the next stage: real 3D classification models and patient
volumes. It supports:

- notGradCAM
- true Grad-CAM through MONAI
- guided Grad-CAM
- LayerCAM
- occlusion
- Integrated Gradients
- Integrated Grad-CAM

Current status:

- Imported as a reference experiment entry point.
- Not wired into the toy 2D deck pipeline yet.
- Requires additional runtime dependencies for real 3D work: `monai`, `scipy`,
  and `scikit-image`, plus a model/data adapter that supplies `patients` and
  `get_stages_fn`.

Deck rule:

- Any 3D heatmap used in the PPT should be generated by this experiment path or
  a reviewed successor, then recorded in a figure manifest before deck export.
